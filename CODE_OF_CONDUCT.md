# Code of Conduct

## The short version

Be decent. Assume the other person is trying.

## What that means here

Most people in this repository are not professional developers — this project
exists partly for people who have never opened a code editor before. A question
that looks obvious to you was not obvious to them, and answering it well is more
useful than answering it fast.

**Expected:** patience with beginners, disagreement about the work rather than
the person, accepting that a maintainer may say no.

**Not accepted:** harassment, personal attacks, demeaning comments about
someone's experience level, publishing anyone's private information, or
sustained disruption.

## Scope

Applies in issues, pull requests, discussions, and anywhere someone is
representing this project.

## Enforcement

Report it through [GitHub's private reporting](https://github.com/eugenezhangco-spec/athena/security/advisories/new)
on this repository. It reaches the maintainers and nobody else, and it does not
require you to have an email address you are comfortable sharing.

Responses run from a private word to a permanent ban, depending on severity and
whether it is a pattern. Maintainers who do not hold this standard themselves
should be reported the same way.
